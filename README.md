# 바른생활 🐢

**AI 컴퓨터 자세 교정 & 스트레칭 코치** (데스크톱 위젯 앱)

웹캠으로 앉은 자세를 실시간으로 분석해요. 화면 구석의 동물 친구가 내 자세를 따라 하고, 거북목이나 구부정한 자세가 오래가면 단계적으로 알려 줘요.

> 카메라 영상은 **저장하거나 전송하지 않고** 내 컴퓨터 안에서만 분석해요.

## 주요 기능

- **실시간 자세 분석**: MediaPipe로 관절을 찾아 거북목, 기울어짐, 턱 괴기 등을 판정
- **개인 기준 자세**: 처음에 10초 동안 바른 자세를 측정해서 나에게 맞춘 기준으로 판정
- **동물 위젯**: 바르게 앉으면 신나게, 자세가 무너지면 같이 무너지는 캐릭터
- **단계적 알림**: 3초 노랑 → 10초 빨강 + 알림 → 화면 흐림 → 교정 유도 화면
- **스트레칭 추천**: 오늘 많았던 자세 문제에 맞춘 스트레칭과 카메라 동작 확인
- **리포트**: 하루·주간 자세 점수
- **기본 모드**: 카메라 없이 사용 시간만으로 셀프 체크

## 설치 방법

학생 프로젝트라 코드 서명이 없어서, 처음 열 때 경고가 떠요. 아래처럼 한 번만 허용하면 돼요.

### Windows
1. `.exe`를 실행해요
2. 파란색 **"Windows의 PC 보호"** 창이 뜨면 **추가 정보 → 실행**을 눌러요

### macOS
1. `.dmg`를 열고 **바른생활**을 **Applications** 폴더로 끌어다 놓아요
2. 응용 프로그램에서 바른생활을 열면 "확인되지 않은 개발자" 경고가 떠요 → **완료**를 눌러 닫아요
3. **시스템 설정 → 개인정보 보호 및 보안**을 열고 아래쪽의 **"그래도 열기"**를 눌러요
4. 카메라 권한을 물어보면 **허용**해요 (기본 모드는 카메라 없이도 돼요)
