# 바른생활 🐢

**AI 컴퓨터 자세 교정 & 스트레칭 코치** (데스크톱 위젯 앱)

웹캠으로 앉은 자세를 실시간으로 분석해요. 화면 구석의 동물 친구가 내 자세를 따라 하고, 거북목이나 구부정한 자세가 오래가면 단계적으로 알려 줘요.

> 카메라 영상은 **저장하거나 전송하지 않고** 내 컴퓨터 안에서만 분석해요.

## 주요 기능

- **실시간 자세 분석**: MediaPipe로 관절을 찾아 거북목, 기울어짐, 턱 괴기 등을 판정
- **개인 기준 자세**: 처음에 10초 동안 바른 자세를 측정해서 나에게 맞춘 기준으로 판정
- **정밀 모드(측면)**: 옆에서 귀–어깨 목 각도(CVA)를 재고, 내 바른 자세 각도를 기준으로 거북목 판정
- **동물 위젯**: 바르게 앉으면 신나게, 자세가 무너지면 같이 무너지는 캐릭터
- **단계적 알림**: 3초 노랑 → 10초 빨강 + 알림 → 화면 흐림 → 교정 유도 화면
- **스트레칭 추천**: 오늘 많았던 자세 문제에 맞춘 스트레칭과 카메라 동작 확인
- **리포트**: 하루·주간 자세 점수
- **기본 모드**: 카메라 없이 사용 시간만으로 셀프 체크

## 0.1.1 업데이트

| 바뀐 점 | 내용 |
|---|---|
| 정밀 모드 개인 기준 | 10초 측정 때 내 목 각도를 저장하고, 그 각도에서 5°씩 내려갈 때마다 한 단계씩 판정 (예전: 모두 50° 고정) |
| 측정 화면 | 옆얼굴 윤곽, 귀–어깨 선과 각도 숫자 표시 |
| 기준 따로 저장 | 웹캠(정면)과 정밀(측면) 기준이 서로 덮어쓰지 않음 |
| 스트레칭 | 5개 → 10개 (목 뒤 늘리기, 고개 돌리기, 가슴 펴기, 몸 비틀기, 눈 쉬기) |
| 버그 수정 | 측정 중 선이 사라짐, 비스듬히 앉으면 반대쪽 귀를 고름, 캐릭터가 마우스에 닿기만 해도 따라옴 등 |

## 설치 방법

학생 프로젝트라 코드 서명이 없어서, 처음 열 때 경고가 떠요. 아래처럼 한 번만 허용하면 돼요.

### Windows
1. `.exe`를 실행해요
2. 파란색 **"Windows의 PC 보호"** 창이 뜨면 **추가 정보 → 실행**을 눌러요

### macOS
1. `.dmg`를 열고 **바른생활**을 **Applications** 폴더로 끌어다 놓아요
2. 응용 프로그램에서 바른생활을 열면 "확인되지 않은 개발자" 경고가 떠요 → **완료**를 눌러 닫아요
3. **시스템 설정 → 개인정보 보호 및 보안**을 열고 아래쪽의 **"그래도 열기"**를 눌러요
4. 카메라 권한을 물어보면 **허용**해요 (기본 모드는 카메라 없이도 돼요)

## 코드에서 직접 실행하기

| 폴더 | 내용 |
|---|---|
| `app/` | 데스크톱 앱 (Electron) |
| `scripts/` | AI 실험: MediaPipe 평가, CVA 규칙, Random Forest, 웹캠 데모 (Python) |
| `webapp/` | 웹 버전 |
| `docs/` | 기획서, 소개 자료 |

1. [MediaPipe Pose Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker) 모델 파일(`pose_landmarker_*.task`)을 받아 `models/` 폴더에 넣어요 (용량이 커서 저장소에는 없어요)
2. `cd app && npm install && npm start`
3. 설치 파일 만들기: `npm run dist:mac` / `npm run dist:win`
